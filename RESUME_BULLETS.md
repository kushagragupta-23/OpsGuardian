# Resume Bullets

- Built **OpsGuardian**, a local-first DevOps incident-resolution RAG copilot using LangChain, LangGraph, Ollama and Chroma to ground troubleshooting answers in runbooks, logs, Kubernetes events, configs, postmortems and historical incidents.
- Implemented **hybrid BM25 + semantic retrieval**, MMR and MultiQuery retrieval with service-aware metadata, structured Pydantic responses and source-backed evidence to distinguish observed signals from possible root causes.
- Created a labelled incident-retrieval benchmark and evaluation pipeline comparing similarity, MMR and hybrid retrieval using source hit, category hit and reciprocal rank, exposed through Streamlit and FastAPI interfaces.
